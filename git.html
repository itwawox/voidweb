Шпаргалка Git

Порядок, которым index.php попадает с диска на GitHub. На каждом шаге одна команда. Пока команду не выполнил, состояние файла не меняется.

Где живёт файл

1. Дискпапка voidweb на Mac
2. Индексчерновик следующего коммита
3. Локальный gitистория в папке .git
4. GitHubgithub.com/itwawox/voidweb
файл создан
git add →
git commit →
git push →

Коммит — это снимок файлов плюс сообщение, зачем он сделан. GitHub видит только то, что ушло через git push.

Порядок команд для index.php

  1. Посмотреть, видит ли git файлшаг 0
    git status
    Ключинет
    Что делаетНичего не записывает. Показывает, какие файлы новые, изменённые или уже в индексе.
    Дискindex.php лежит в папке.
    Индекспусто
    Локальный gitкоммитов нет. Ветка main пустая.
    GitHubрепозиторий пустой, файла нет.
    Как выглядитUntracked files: index.php — git файл видит и ещё не хранит.
  2. Положить файл в черновик коммиташаг 1
    git add index.php
    Ключинет. index.php — это имя файла, не ключ.
    Что делаетКопирует текущее содержимое файла в индекс. На GitHub ничего не уходит.
    Дискфайл на месте, содержимое то же.
    Индексindex.php подготовлен.
    Локальный gitкоммита всё ещё нет.
    GitHubпусто.
    Как выглядитповторный git status показывает файл зелёным: new file: index.php.

    git add . кладёт в индекс всё, что не закрыто .gitignore. Точка — «текущая папка». Папку .grok/ так лучше не захватывать: это настройки редактора, не сайт.

  3. Записать снимок в локальную историюшаг 2
    git commit -m "Add test index.php"
    Ключи-m — сообщение коммита сразу в команде. Текст в кавычках обязателен: без него git откроет редактор.
    Что делаетБерёт индекс и сохраняет коммит в .git. Это уже история, но только на этом Mac.
    Дискфайл на месте.
    Индексчерновик стал коммитом, новых правок в индексе нет.
    Локальный gitкоммит c2ed292, ветка main. Сообщение: Add test index.php. В коммите 1 файл, 21 строка.
    GitHubпока пусто. Коммит локальный.
    АвторИмя и почта git взял с компьютера: ivanromanov@Ivans-MacBook-Air.local. Это предупреждение, коммит из-за него не отменяется.
  4. Подписать следующие коммиты аккаунтом GitHubшаг 3, один раз
    git config --global user.name "Иван Романов"
git config --global user.email "30245303+itwawox@users.noreply.github.com"
    Ключи--global — записать настройку для всего Mac, не только для этой папки.
    Что делаетМеняет имя автора для будущих коммитов. Файл index.php и коммит c2ed292 не трогает.
    Диск / индекс / GitHubбез изменений.
    Почта30245303+itwawox@users.noreply.github.com — служебный адрес GitHub для аккаунта itwawox. Письма на него не приходят, в профиле он не светится, зато коммит привязывается к аккаунту.

    Уже сделанный коммит можно переподписать, только если он ещё не ушёл на GitHub: git commit --amend --reset-author. --amend переписывает последний коммит. --reset-author ставит в него имя и почту из настройки выше. После git push этот коммит уже не переписывают.

  5. Отправить историю на GitHubшаг 4
    git push -u origin main
    Ключи-u — запомнить связь локальной main с origin/main. Пишется один раз. Дальше достаточно git push.
    originимя удалённого репозитория. Указывает на https://github.com/itwawox/voidweb.git.
    mainветка, которую отправляем.
    Что делаетКопирует локальные коммиты на GitHub. Логин уже есть: аккаунт itwawox, протокол HTTPS, пароль спрашивать не должен.
    Диск и индексбез изменений.
    Локальный gitтот же коммит c2ed292.
    GitHubпоявляется ветка main и файл index.php.
  6. Проверить, что история на местепосле отправки
    git status
git log --oneline
    Ключи--oneline — одна строка на коммит: короткий хеш и сообщение.
    Чистый статусnothing to commit, working tree clean — на диске нет новых правок сверх последнего коммита.
    Связь с GitHubYour branch is up to date with 'origin/main' — локальная ветка и GitHub совпадают.

Если файл изменили ещё раз

Правка в редакторе снова делает файл «грязным» только на диске. Старый коммит на GitHub остаётся прежним, пока не повторишь три команды:

git add index.php
git commit -m "Коротко, зачем правка"
git push

Ключ -u во второй раз не нужен: связь с origin/main уже записана.

Что в эти команды не попадает

.env, пароли, ключизакрывает .gitignore. В этом репозитории там же закрыты .grok/, vendor/ и node_modules/.
.grok/настройки редактора. В статус попадает как неотслеживаемая папка. В git add её не включают.
Картинка-логотип сайтакоммитится так же, как index.php, если это часть проекта.
Файл, который пользователь загрузил на сайтданные приложения, не исходный код. В учебный коммит его не кладут.
